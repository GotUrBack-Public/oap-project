# Objectives as Policies

Project website for **Objectives as Policies: Vision-Language Model Cost Programs for Contact-Rich Manipulation** by Zihao Lu*, Trong Gia Hung Nguyen*, Fuquan Wang, and Yifan Zhu (University of Illinois Chicago). The first two authors contributed equally.

[Project page](https://zihaolu001.github.io/oap-project/) · [arXiv:2611.18298](https://arxiv.org/abs/2611.18298) · [Research code](https://github.com/ZihaoLu001/OaP)

## Editing

GitHub Pages serves the root of `main`. Run `python -m http.server 8000` in this directory and open `http://localhost:8000` for a local preview.

Edit `index.html` for page content and `static/js/index.js` for the task selector. The four clips have matching posters and recorded-state comparison frames. Playback duration is independent of the robot's execution time.

The Paper PDF button opens the current version on arXiv. The existing local link, `static/paper/oap.pdf`, serves a copy of arXiv v1. The BibTeX entry follows the [arXiv export](https://arxiv.org/bibtex/2611.18298).
