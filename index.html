Abstract

Vision-language models (VLMs) have shown strong semantic and spatial reasoning capabilities in 3D environments. Recently, connecting VLMs with model-predictive controllers (MPC) has emerged as a paradigm for combining strong semantic reasoning with physics-based planning. However, connecting these two for contact-rich robotic manipulation requires a task representation that bridges the two and captures how physical interactions can be reasoned about by VLMs.

In this work, we introduce Objectives as Policies (OaP), a framework that connects a pretrained VLM to a shared sampling-based MPC through an editable objective program. Each program specifies a sequence of stages for completing a task, combining running and terminal costs from a cost library with stage completion conditions. Given a natural-language task instruction and scene observation, we build a simulation-based digital twin through real-to-sim, and the VLM generates an objective program that the MPC executes in simulation. The VLM iteratively updates the program based on MPC rollouts before deployment in the real world. We evaluate OaP in simulation and on a physical robot across four tabletop manipulation tasks.

Method

Generate an objective program

The VLM uses the task instruction, scene observation, and cost library to specify stages, running costs, terminal costs, and completion conditions.

Refine in simulation

A shared MPC executes the program in the digital twin. The VLM uses execution feedback to revise the program before deployment.

Execute on the robot

The MPC replans from the measured state using the fixed program. A stage verifier advances the task when its completion conditions are met.
